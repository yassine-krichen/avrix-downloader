# Icon Design Prompts

Use these prompts with AI image generators (DALL-E, Midjourney, etc.) or share with a designer:

## Main App Icon (icon.png)

**Prompt for AI:**
```
Create a modern, flat design app icon for a YouTube downloader application. 
The icon should feature:
- A red YouTube play button symbol
- A blue downward arrow indicating download
- Circular or rounded square background
- Colors: Red (#FF0000) and Blue (#1976d2)
- Minimalist, clean design
- 256x256 pixels
- PNG format with transparency
- Works well at small sizes (16x16 to 256x256)
```

**Visual Description:**
```
┌─────────────┐
│   ░░░░░░░   │  
│  ░▶████░░░  │  <- Red play button
│  ░░░░░║░░░  │  
│  ░░░░░▼░░░  │  <- Blue download arrow
│   ░░░░░░░   │
└─────────────┘
```

## App Logo (logo.png) - Optional

**Prompt for AI:**
```
Create a horizontal logo for "YouTube Downloader Pro" application.
The logo should include:
- An icon on the left (similar to main app icon)
- Text "YouTube Downloader Pro" on the right
- Modern, professional font
- Colors: Blue (#1976d2) and Red accents
- Transparent background
- 512x512 pixels
- Suitable for use on both light and dark backgrounds
```

## Quick Online Tools

### Create Icons:
1. **Canva** - https://www.canva.com/
   - Use "App Icon" template
   - 256x256 size

2. **Figma** - https://www.figma.com/
   - Free, professional tool
   - Export as PNG

3. **Adobe Express** - https://www.adobe.com/express/
   - Quick icon creator
   - Free templates

### Convert to ICO:
1. **ConvertICO** - https://convertico.com/
2. **CloudConvert** - https://cloudconvert.com/png-to-ico

## Design Checklist

Before finalizing your icon:
- ✅ Looks clear at 16x16 pixels (taskbar size)
- ✅ Recognizable at 256x256 pixels (full size)
- ✅ Works on both light and dark backgrounds
- ✅ Uses brand colors (blue primary)
- ✅ Instantly conveys "download" concept
- ✅ Professional and modern appearance
- ✅ No text (icons should be symbolic)
- ✅ Transparent background (PNG)

---

## Once You Have the Icon

1. Save as `icon.png` in the `assets/` folder
2. Optionally convert to `icon.ico` for Windows
3. Restart the app
4. Icon will appear in:
   - Window title bar
   - Windows taskbar
   - Alt+Tab switcher
   - Desktop shortcut (if created)
